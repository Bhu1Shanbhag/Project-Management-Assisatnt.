# AI Project Intelligence Platform — Backend Dependencies
#
# REQUIRES PYTHON 3.12.x — do not use 3.13 or 3.14.
#   chromadb 0.5.5 pins numpy<2.0.0, so the resolver picks numpy 1.26.4, and
#   1.26.4 is the last numpy publishing wheels for Python <=3.12. On 3.13+ pip
#   compiles numpy from source and that build mis-detects longdouble, so
#   `import numpy` dies with:
#       OverflowError: cannot convert longdouble infinity to integer
#   Lifting this restriction requires upgrading chromadb past the numpy<2 cap.
#
# Install (from the repo root):
#   py -3.12 -m venv .venv
#   .venv\Scripts\Activate.ps1
#   python -m pip install -r backend\requirements.txt
#
# Prefer `python -m pip` over the pip.exe shim — the shim hardcodes an absolute
# interpreter path at creation time and breaks if the venv is copied or its
# parent folder is renamed.
#
# Versions below are pinned to a set verified working on Python 3.12.10.
